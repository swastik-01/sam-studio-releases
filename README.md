# SAM releases

Installers for SAM, the assistant for code, slides, designs and videos that runs its AI models on your own computer.

Download the latest Windows installer from [Releases](../../releases/latest). Installed copies of SAM look here for new versions now and then and install them when SAM restarts (you can turn that off in Settings → About).

The source code is private; third-party notices ship with the app (Settings → About → Third-party notices).
